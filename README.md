# KahWee Teng

I’m a Staff Software Engineer focused on frontend architecture and developer experience. I build reusable UI components and tools for developers.

## Selected work

- **[BaseUI TanStack Form](https://github.com/kahwee/baseui-tanstack-form)**: React form fields connecting TanStack Form and Base Web, with reusable form sections and Zod helpers. [Examples](https://kahwee.github.io/baseui-tanstack-form/?path=/story/form-components-input--default).
- **[BaseUI TanStack Table](https://github.com/kahwee/baseui-tanstack-table)**: Typed React tables with search, sorting, row selection and server pagination. [Examples](https://kahwee.github.io/baseui-tanstack-table/?path=/story/components-checkboxtable--default).
- **[Ratagrid](https://github.com/kahwee/ratagrid)**: A typed data grid for Ratatui, bringing sorting, search, selection and pagination to terminal interfaces.
- **[ChHeader](https://github.com/kahwee/ch-header)**: A Chrome extension for editing HTTP headers, with local profiles and explicit website permissions.

I write about the decisions and debugging behind my work at [kahwee.com](https://kahwee.com/).
