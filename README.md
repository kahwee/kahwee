## Selected work

### [BaseUI TanStack Form](https://github.com/kahwee/baseui-tanstack-form)
**React · TypeScript · TanStack Form · Base Web**

Build forms with reusable fields and sections rather than wiring each control from scratch. Includes text, choice and date controls, submission states, and optional Zod helpers.

[Explore the examples](https://kahwee.github.io/baseui-tanstack-form/) · [Form composition guide](https://github.com/kahwee/baseui-tanstack-form/blob/main/FORM_COMPOSITION.md)

### [BaseUI TanStack Table](https://github.com/kahwee/baseui-tanstack-table)
**React · TypeScript · TanStack Table · Base Web**

Typed tables for browsing and selecting data. Handles search, sorting, loading and empty states, with optional server pagination and controlled row selection.

[Explore the examples](https://kahwee.github.io/baseui-tanstack-table/) · [Columns and pagination guide](https://github.com/kahwee/baseui-tanstack-table/blob/main/docs/usage.md)

### [Ratagrid](https://github.com/kahwee/ratagrid)
**Rust · Ratatui**

A typed data grid for terminal applications, with sorting, search, selection, column resizing and pagination. The application keeps control of its terminal and data source.

[Documentation and demo](https://kahwee.github.io/ratagrid/) · [API reference](https://docs.rs/ratagrid)

### [ChHeader](https://github.com/kahwee/ch-header)
**Chrome extension · TypeScript**

Edit HTTP request and response headers using local profiles and explicit website permissions. I built it to have a header editor without ads, with source anyone can inspect.

[Install for Chrome](https://chromewebstore.google.com/detail/chheader/okmjidkmnlobbppegojfcedhaakadgig) · [Why I built it](https://kahwee.com/2026/why-i-built-chheader/)
